Satu langkah lagi: hubungkan penyimpanan

Halaman ini butuh database gratis (Firebase) supaya nilai yang Anda isi tersimpan dan langsung terlihat di semua HP. Ikuti langkah ini sekali saja:

  1. Buka console.firebase.google.com → Add project → beri nama bebas → lanjutkan (boleh matikan Google Analytics).
  2. Di menu kiri, klik Build → Realtime Database → Create Database → pilih lokasi → mulai dalam test mode.
  3. Di menu kiri atas (ikon gerigi) → Project settings → scroll ke Your apps → klik ikon </> (Web) → beri nama app → Register app.
  4. Firebase akan menampilkan kode firebaseConfig = {'{'} apiKey: "...", ... {'}'}. Salin seluruh isinya.
  5. Buka file index.html ini di GitHub (edit langsung di browser, ikon pensil), cari tulisan const firebaseConfig = { ... } di bagian bawah, dan ganti dengan yang Anda salin tadi. Simpan (commit).
  6. Kembali ke tab Realtime Database → Rules di Firebase, ganti isinya jadi:
    { "rules": { ".read": true, ".write": true } }
    lalu klik Publish.

Setelah itu, muat ulang halaman ini — sudah bisa dipakai dan tersimpan otomatis ke semua orang yang membuka tautannya.
